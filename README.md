# SmartLibrary

## BSE2201 Software Engineering Foundations

**Group:** 5th Generation
**Project:** SmartLibrary Landing Page

## About the Project

SmartLibrary is a proposed library management system designed to improve the way library resources are managed and accessed.

The system aims to make it easier for librarians to manage books and for students to search for available books, borrow books, and return them.

This project focuses on creating a responsive landing page that introduces the SmartLibrary system, its features, benefits, and development team.

## Project Objectives

* Explain the problems faced in traditional library management.
* Introduce the proposed SmartLibrary system.
* Show the main features and benefits of the system.
* Provide information about the development team.
* Create a responsive and user-friendly landing page.

## Landing Page Sections

The website contains the following sections:

* Home
* Problem
* SmartLibrary
* Features
* Team
* Contact

## Main Features

### Book Management

Librarians can add, edit, delete, and search for books.

### Borrowing and Returning

The system keeps track of borrowed books, borrowing dates, expected return dates, and returned books.

### Book Availability

Users can check whether a book is available or already borrowed.
